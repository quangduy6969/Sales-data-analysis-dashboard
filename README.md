# Sales Data Analysis Dashboard

## Project Overview

This project analyzes sales data using Microsoft Excel.

## Tools Used

* Microsoft Excel
* Pivot Table
* Pivot Chart
* Dashboard

## Analysis Included

* Monthly Revenue Trend
* Revenue Distribution by Category
* Profit by Category
* Sales by Region
* Top 10 Customers by Revenue

## Key Insights

* Technology generated the highest revenue and profit
* Revenue increased significantly at the end of the year
* West region had the highest sales
* Top customers contributed a large portion of total revenue

## Dataset

* Dataset used: Sample Superstore Dataset
* Source:

  * Tableau Sample Superstore Dataset
  * Kaggle
* The dataset contains sales transaction information including revenue, profit, customer, category, and regional performance.
